# 卒業制作 起動方法

この文書では、Flutter版「卒業制作」をWindowsのPowerShellから起動する方法をまとめます。

プロジェクトの保存場所:

```text

```

## 1. Web版

### 初回起動

PowerShellを開き、次を上から順番に実行します。

```powershell
cd ファイルのある場所

flutter doctor -v
flutter pub get
flutter devices
flutter run -d chrome
```

Chromeが自動的に開き、Web版が表示されます。

### 2回目以降

通常は次の2行だけで起動できます。

```powershell
cd ファイルのある場所
flutter run -d chrome
```

### iPhoneなど、同じWi-Fi内の端末から確認する場合

PCと確認用端末を同じWi-Fiへ接続して、次を実行します。

```powershell
cd ファイルのある場所
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080
```

別のPowerShellでPCのIPv4アドレスを確認します。

```powershell
ipconfig
```

表示されたIPv4アドレスが、例えば `192.168.1.10` の場合、端末のブラウザで次を開きます。

```text
http://192.168.1.10:8080
```

Windowsファイアウォールの確認が表示された場合は、プライベートネットワークでのアクセスを許可します。この方法は開発中の確認用です。外部公開用のWeb版は、後でホスティング環境へ配置します。

## 2. Android実機版

現在使用している端末:

```text
端末名: SH-52E
デバイスID: SX4LHMA4B0811121
```

### 初回起動

事前にAndroid端末側で以下を済ませます。

1. 開発者向けオプションを有効にする
2. USBデバッグを有効にする
3. USBケーブルでPCと接続する
4. 端末にUSBデバッグ許可画面が出たら許可する

その後、PowerShellで次を実行します。

```powershell
cd ファイルのある場所

flutter doctor -v
flutter pub get
flutter devices
flutter run -d SX4LHMA4B0811121
```

ビルド完了後、Android端末へアプリがインストールされ、自動的に起動します。ホーム画面では「卒業制作」と表示されます。

### 2回目以降

端末をUSB接続し、USBデバッグが有効な状態で次を実行します。

```powershell
cd ファイルのある場所
flutter run -d SX4LHMA4B0811121
```

既にインストールされているアプリへ最新コードが上書きされます。通常はアンインストール不要です。

## 3. 開発中によく使う操作

`flutter run`を実行しているPowerShell上で、以下のキーを使用できます。

- `r`: Hot Reload。画面を維持したままコード変更を反映する
- `R`: Hot Restart。アプリを最初から再起動する
- `h`: 使用可能なコマンドを表示する
- `q`: 実行を終了する

コードを編集して保存した後は、通常は`r`で確認できます。初期化処理や依存関係を変更した場合は`R`、または一度`q`で終了して再実行します。

## 4. 起動できない場合

### 共通の復旧手順

```powershell
cd ファイルのある場所

flutter clean
flutter pub get
flutter analyze
flutter test
```

問題がなければ、WebまたはAndroidの起動コマンドをもう一度実行します。

### Android端末が表示されない場合

```powershell
adb kill-server
adb start-server
flutter devices
```

それでも表示されない場合は、以下を確認します。

- USBケーブルを挿し直す
- 充電専用ではなく、データ通信対応ケーブルを使用する
- Android端末のUSBデバッグが有効か確認する
- 端末側のUSBデバッグ許可画面を確認する

### Gradleのキャッシュがロックされた場合

```powershell
cd ファイルのある場所\android
.\gradlew.bat --stop

cd ファイルのある場所
flutter clean
flutter pub get
flutter run -d SX4LHMA4B0811121
```

### Dartコンパイラの一時ファイルでエラーが出る場合

現在のPowerShellだけで、プロジェクト内の一時フォルダを使用します。

```powershell
cd ファイルのある場所

$flutterTemp = Join-Path (Get-Location) ".flutter_temp"
New-Item -ItemType Directory -Force -Path $flutterTemp | Out-Null
$env:TEMP = $flutterTemp
$env:TMP = $flutterTemp

flutter run -d SX4LHMA4B0811121
```

Web版の場合は、最後の行を次に変更します。

```powershell
flutter run -d chrome
```

## 5. 配布用ファイルの生成

普段の動作確認には必要ありません。提出や他の端末への配布が必要になったときに使用します。

### AndroidデバッグAPK

```powershell
cd ファイルのある場所
flutter build apk --debug
```

生成場所:

```text
build\app\outputs\flutter-apk\app-debug.apk
```

### Web公開用ファイル

```powershell
cd ファイルのある場所
flutter build web --release
```

生成場所:

```text
build\web
```
